# The follow-up meeting

One line about office life, written by `main.py` to `/output/entry.txt`.
The entry uses only the Python standard library, so it needs no install step
and no network access at grading time.

The joke: "I sent a 'quick question' and got a 47-minute meeting. The
follow-up is a meeting about why we had a meeting."
